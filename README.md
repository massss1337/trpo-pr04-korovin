# Практическая работа №4

PHP. Основы языка, запросы и обработка HTML-форм.

## Назначение

Приложение для просмотра сотрудников и обработки заявок.

## Технологии

- PHP 8+
- HTML5

## Структура проекта

- public/index.php — точка входа и HTML-страница.
- src/functions.php — пользовательские функции.
- dataset/employees.csv — исходные данные сотрудников.
- dataset/form_cases.json — сценарии проверки формы.
- data — каталог для данных приложения.

## Запуск

Откройте терминал в корневой папке проекта и выполните:

```bash
php -S localhost:8000 -t public
```

Откройте в браузере:

http://localhost:8000

Для остановки сервера нажмите Ctrl+C в терминале.

## Загрузка сотрудников

Сотрудники загружаются из dataset/employees.csv.

Функция loadEmployees читает CSV с разделителем «;».
Функция normalizeEmployee преобразует строку в ассоциативный массив:
идентификатор и стаж становятся целыми числами, строковые значения
очищаются от пробелов по краям.

HTML получает подготовленный массив сотрудников.
Строковые значения выводятся через escapeHtml.

При недоступном файле или неверной структуре CSV отображается
сообщение об ошибке. Для пустого списка предусмотрено отдельное состояние.

Оформление находится в public/style.css.

## Обработка формы

Форма заявки содержит четыре поля: имя, отдел, стаж и email.
Данные отправляются методом POST.

Отсутствующие значения обрабатываются оператором ??.
Функция normalizeText удаляет пробелы по краям строк через trim.
Функция validateInput возвращает массив ошибок.

Правила проверки:
- имя — от 2 до 100 символов;
- отдел — из списка отделов сотрудников;
- стаж — целое число от 0 до 60 лет;
- email — корректный адрес длиной не более 254 символов.

При ошибках форма сохраняет введённые значения.
После успешной проверки показывается подтверждение с данными заявки.
Данные заявки обрабатываются в рамках текущего запроса.

Пользовательские значения выводятся через escapeHtml,
которая вызывает htmlspecialchars.

Для проверки длины строк используется расширение PHP mbstring.

## Фильтрация сотрудников

Форма фильтра использует метод GET и параметр department.
Список отделов формируется из employees.csv.

Функция filterEmployees возвращает сотрудников выбранного отдела.
Если параметр отсутствует или пуст, отображаются все записи.
Для неизвестного отдела показывается пустой результат.
Ссылка «Сбросить» открывает страницу без параметра фильтра.

## Различие GET и POST

GET используется для получения и фильтрации данных.
Параметры находятся в адресе страницы, поэтому ссылку с фильтром
можно сохранить или передать другому пользователю.

POST используется для отправки заявки на обработку.
Значения полей передаются в теле HTTP-запроса.

## Безопасный вывод

Функция htmlspecialchars преобразует специальные символы HTML
в безопасное представление. Введённые пользователем строки
выводятся как текст, а не исполняются как HTML-разметка.

## Путь данных

Браузер отправляет форму POST-запросом в public/index.php.
Значения извлекаются из $_POST с оператором ?? и нормализуются
функцией normalizeText. Затем validateInput проверяет данные.

При ошибках страница выводит сообщения и повторно заполняет форму.
При успехе отображается подтверждение с данными заявки.
Перед выводом пользовательские строки проходят через escapeHtml.

## Проверка сценариев

Файл tests/form_cases.php читает dataset/form_cases.json,
вызывает валидатор и сравнивает результат с ожидаемым.

В сценариях заданы имя и стаж. Остальные обязательные поля
заполняются корректными значениями.

Запуск из корня проекта:

```bash

php tests/form_cases.php
```

Ожидаемый результат: три пройденные проверки, ноль ошибок.

Проверка синтаксиса:

```bash
php -l src/functions.php
php -l public/index.php
php -l tests/form_cases.php
```
